# Dynamic Universe

## UniverseSpace / All

`All` is an invisible technical attachment for a semantic, continuous R³ runtime—not a playable Minecraft dimension. See [SPECS.md](SPECS.md) for the `UniverseHost`, persisted `UniverseRuntimeState`, multi-bubble floating origin and globe-projection architecture. The visible universe is rendered from geometric body meshes whose surfaces sample toroidal local dimensions.

Dynamic Universe is an independent Kotlin/NeoForge mod for Minecraft 1.21.1. It provides server-authoritative celestial-body simulation and finite, toroidal horizontal topology.

It has no dependency on TerrArchitecture or DynamicDimensions. Immersive Portals and Sable are optional compatibility targets; the base mod starts without them. Distant Horizons is supported through a data-only topology contract, so it also remains optional.

See [SPECS.md](SPECS.md) and [the dependency policy](docs/DEPENDENCIES.md).
